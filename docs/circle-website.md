# دایره — وب‌سایت و هویت

وب‌سایت شرکت نرم‌افزاری دایره در `client/` است و برای `circlegroup.ir` طراحی شده است.

## منطق طراحی

«نظم درون دایره»: نام از علاقه به فرم‌های گرد آمده و نگاه شرکت، اتصال آدم‌ها، داده‌ها و ابزارهای کسب‌وکار به یک سیستم منسجم است. نشان منتخب از حرف «ه» الهام می‌گیرد و با مسیرهای SVG تعریف شده؛ تصویر یا اسکرین‌شات منبع لوگو نیست.

- زمینهٔ کاغذی گرم، متن نفتی و تأکیدهای محدود مسی؛ از پالت کیت برند.
- نام فارسی با «ه» اختصاصی در سربرگ؛ نشان مستقل در نمودارها و روایت برند.
- دایره، قوس، خط اتصال و فاصلهٔ کافی، عناصر مشترک صفحه‌ها هستند.
- تیترهای فارسی بدون تغییر فاصلهٔ حروف، با Vazirmatn محلی و دارای مجوز OFL.
- نمونه‌کارها تصویرهای مفهومی از حوزهٔ پروژه دارند؛ این تصویرها اسکرین‌شات مشتری نیستند و آمار یا نتیجهٔ تأییدنشده نمایش نمی‌دهند.

## صفحه‌ها و رفتارها

صفحهٔ اصلی شامل نمودار تعاملی خدمات، پروژه‌های منتخب، محصولات مدیریت انبار و کنترل کیفیت، مسیر همکاری و داستان نام دایره است. انتخاب هر بخش نمودار، توضیح و پیوند مربوط به همان خدمت را نمایش می‌دهد.

صفحهٔ راهکارها چهار حوزهٔ خدمات و پرسش‌های متداول را توضیح می‌دهد. پیوندهای مستقیم مانند `/services#software-api` به بخش درست می‌روند. صفحهٔ کارها پروژه‌های موجود مخزن را با فیلترهای وب‌سایت، نرم‌افزار و اپلیکیشن نمایش می‌دهد؛ هر پروژه صفحهٔ معرفی و پیوند وب‌سایت اصلی دارد.

دربارهٔ دایره، داستان واقعی نام و نشان «ه» را توضیح می‌دهد. فرم تماس نام، ایمیل و پیام را الزامی می‌کند؛ موضوع و نام کسب‌وکار اختیاری‌اند. پیوندهای درخواست دمو و خدمات، موضوع گفت‌وگو را با `?service=` انتخاب می‌کنند. فرم همچنان به Formspree با شناسهٔ موجود متصل است و حالت موفقیت، خطای فارسی و امکان تلاش دوباره دارد. اطلاعات تماس از نشانی ایمیل موجود استفاده می‌کند؛ شمارهٔ تلفن نمونه نمایش داده نمی‌شود.

صفحه‌های حریم خصوصی، شرایط استفاده، ۴۰۴، خطا و وضعیت بارگذاری هم از همین زبان بصری پیروی می‌کنند. منوی موبایل با Escape بسته می‌شود؛ لینک پرش به محتوا، فوکوس قابل مشاهده و کاهش حرکت پشتیبانی می‌شوند.

## اجرا و بررسی

از ریشهٔ مخزن:

```bash
cd client
npm ci
npm run dev
npm run build
npm run preview
```

فایل‌های مشترک رابط در `src/components/site/`، محتوای هویت در `src/data/identity.ts` و سبک وب‌سایت در `src/styles/site.css` هستند. داده‌های واقعی پروژه‌ها و خدمات در `src/data/site.ts` باقی می‌مانند. کیت قابل استفادهٔ لوگو و امضا در `src/brand/circle/` مستند شده است.

## انتشار

گردش کار GitHub Pages با push به `main` خروجی `client/dist` را منتشر می‌کند. شاخه‌های کاری سایت زنده را منتشر نمی‌کنند. `public/CNAME` و متادیتای اشتراک‌گذاری به `circlegroup.ir` اشاره می‌کنند.

یک build برای دامنهٔ اختصاصی و مسیر پروژهٔ GitHub Pages قابل استفاده است. عنصر base در `index.html` مسیر فایل‌ها را هنگام بازکردن URLهای تو‌در‌تو ثابت نگه می‌دارد؛ `public/404.html` مسیرهای ناشناختهٔ Pages را به برنامه برمی‌گرداند. helper مسیر عمومی و basename روتر، مسیر پروژهٔ GitHub Pages را حفظ می‌کنند.

در بررسی فرم، پاسخ موفق و خطای Formspree باید شبیه‌سازی شوند تا پیام آزمایشی واقعی ارسال نشود. بازکردن لینک‌های مشتری و ارسال فرم واقعی بخشی از آزمون خودکار رابط نیست.
