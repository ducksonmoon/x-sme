📋 پارامترهای جدید

پارامترهای جدید برای شخصی‌سازی لوگو و رنگ‌ها:

نام پارامتر نوع پیش‌فرض توضیحات
customLogo string null URL لوگوی سفارشی (جایگزین لوگوی کسب‌وکار)
primaryColor string #3b82f6 رنگ اصلی برای دکمه‌ها و عناصر مهم
secondaryColor string null رنگ ثانویه برای گرادیان‌ها و افکت‌ها
🎨 رنگ‌های سفارشی پایه جدید
استفاده از رنگ‌های سفارشی برای شخصی‌سازی ظاهر ویجت
<div id="xsme-booking-widget" data-business-id="your-business-id" data-primary-color="#8b5cf6" data-secondary-color="#a855f7"> </div>
🖼️ لوگوی سفارشی جدید
استفاده از لوگوی سفارشی به جای لوگوی پیش‌فرض کسب‌وکار

🔧 نحوه استفاده

برای استفاده از قابلیت‌های جدید، کافی است پارامترهای زیر را به تگ HTML اضافه کنید:

<!-- مثال کامل با تمام قابلیت‌ها --> <div id="xsme-booking-widget" data-business-id="your-business-id" data-custom-logo="https://your-domain.com/logo.png" data-primary-color="#3b82f6" data-secondary-color="#6366f1" data-theme="auto" data-show-logo="true" data-border-radius="12"> </div> <script src="https://your-domain.com/widget.js"></script>

🎯 نکات مهم

  • لوگوی سفارشی: باید URL معتبر و قابل دسترس باشد
  • رنگ‌ها: از فرمت HEX استفاده کنید (مثل #3b82f6)
  • رنگ ثانویه: اختیاری است و برای گرادیان‌ها استفاده می‌شود
  • سازگاری: با تمام مرورگرهای مدرن سازگار است
  • عملکرد: تغییر رنگ‌ها تأثیری بر عملکرد ویجت ندارد
