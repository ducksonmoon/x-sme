🔧 نحوه استفاده (فقط ۲ خط کد!)

برای اضافه کردن ویجت رزرو به سایت خود، فقط کافی است این کدها را کپی کنید:

مرحله ۱: اضافه کردن اسکریپت

<script src="https://widget.x-sme.ir/widget.js"></script>

مرحله ۲: اضافه کردن ویجت (حداقل)

<div id="xsme-booking-widget" data-business-id="YOUR_BUSINESS_ID"> </div>

تنظیمات کامل (اختیاری)

<div id="xsme-booking-widget" data-business-id="demo-business-123" data-theme="light" /* light, dark */ data-language="fa" /* fa, en */ data-primary-color="#ec4899" /* رنگ اصلی */ data-border-radius="12" /* گردی گوشه‌ها */ data-show-logo="true" /* نمایش لوگو */ data-show-business-info="true" /* نمایش اطلاعات کسب‌وکار */ data-allow-notes="true" /* امکان افزودن یادداشت */ data-require-email="false" /* الزامی بودن ایمیل */ data-max-advance-booking="30" /* حداکثر روز رزرو از قبل */ data-min-advance-booking="2"> /* حداقل ساعت رزرو از قبل */ </div>

جدول تنظیمات کامل

پارامتر نوع مقدار پیش‌فرض توضیحات
data-business-id متن - الزامی: شناسه کسب‌وکار
data-theme متن light تم رنگی: light، dark
data-language متن fa زبان: fa (فارسی)، en (انگلیسی)
data-primary-color رنگ #3b82f6 رنگ اصلی ویجت (HEX)
data-border-radius عدد 8 گردی گوشه‌ها (پیکسل)
data-show-logo منطقی true نمایش لوگو کسب‌وکار
data-show-business-info منطقی true نمایش اطلاعات کسب‌وکار
data-allow-notes منطقی true امکان افزودن یادداشت توسط مشتری
data-require-email منطقی false الزامی بودن ایمیل
data-max-advance-booking عدد 30 حداکثر تعداد روز رزرو از قبل
data-min-advance-booking عدد 2 حداقل تعداد ساعت رزرو از قبل

جدول رویدادهای کامل

رویداد تابع Callback Event Listener دیتای ارسالی توضیحات
ایجاد ویجت xsmeOnCreated xsme:created containerId, businessId, config هنگام ایجاد ویجت
بارگذاری ویجت xsmeOnLoaded xsme:loaded containerId, businessId, config هنگام بارگذاری کامل ویجت
آماده شدن ویجت xsmeOnReady xsme:ready containerId, businessId, config هنگام آماده شدن ویجت برای استفاده
شروع رزرو xsmeOnBookingStarted xsme:booking:started businessId, timestamp هنگام شروع فرآیند رزرو
انتخاب سرویس xsmeOnServiceSelected xsme:service:selected serviceId, serviceName, price هنگام انتخاب سرویس توسط مشتری
انتخاب تاریخ xsmeOnDateSelected xsme:date:selected date, dayOfWeek هنگام انتخاب تاریخ رزرو
انتخاب زمان xsmeOnTimeSelected xsme:time:selected time, slot هنگام انتخاب زمان رزرو
تکمیل رزرو xsmeOnBookingComplete xsme:booking:complete id, businessId, serviceName, amount, date, time هنگام تکمیل موفق رزرو
لغو رزرو xsmeOnBookingCancelled xsme:booking:cancelled reason, step هنگام لغو رزرو توسط مشتری
خطا xsmeOnError xsme:error type, error, containerId هنگام بروز خطا در ویجت

رویدادهای JavaScript (اختیاری)

روش ۱: Callback Functions (ساده)

<script> // رویداد تکمیل رزرو window.xsmeOnBookingComplete = function(booking) { console.log('✅ رزرو تکمیل شد:', booking); alert(`رزرو شما با شماره ${booking.id} ثبت شد!`); }; // رویداد شروع رزرو window.xsmeOnBookingStarted = function(data) { console.log('🎬 شروع فرآیند رزرو:', data); // کد دلخواه شما }; // رویداد انتخاب سرویس window.xsmeOnServiceSelected = function(service) { console.log('🔧 سرویس انتخاب شد:', service); // به‌روزرسانی UI یا ارسال آمار }; // رویداد انتخاب تاریخ window.xsmeOnDateSelected = function(date) { console.log('📅 تاریخ انتخاب شد:', date); }; // رویداد انتخاب زمان window.xsmeOnTimeSelected = function(time) { console.log('⏰ زمان انتخاب شد:', time); }; // رویداد خطا window.xsmeOnError = function(error) { console.error('❌ خطا در ویجت:', error); // نمایش پیام خطای سفارشی }; // رویداد آماده شدن ویجت window.xsmeOnReady = function(data) { console.log('🚀 ویجت آماده است:', data); }; </script>

روش ۲: Event Listeners (پیشرفته)

<script> // استفاده از Event Listeners برای کنترل بهتر document.addEventListener('xsme:booking:complete', function(event) { const booking = event.detail; console.log('رزرو تکمیل شد:', booking); // ارسال به گوگل آنالیتیکس if (window.gtag) { gtag('event', 'booking_complete', { booking_id: booking.id, business_id: booking.businessId, service_name: booking.serviceName, amount: booking.amount }); } // ارسال به فیسبوک پیکسل if (window.fbq) { fbq('track', 'Purchase', { value: booking.amount, currency: 'IRR' }); } // نمایش modal تأیید سفارشی showCustomSuccessModal(booking); }); // گوش دادن به رویدادهای مختلف const events = [ 'xsme:booking:started', 'xsme:booking:cancelled', 'xsme:service:selected', 'xsme:date:selected', 'xsme:time:selected', 'xsme:error', 'xsme:ready' ]; events.forEach(eventName => { document.addEventListener(eventName, function(event) { console.log(`رویداد ${eventName}:`, event.detail); // آمارگیری if (window.dataLayer) { dataLayer.push({ event: eventName.replace(':', '_'), widget_data: event.detail }); } }); }); // گوش دادن به رویدادهای یک ویجت خاص const widget = document.getElementById('xsme-booking-widget'); widget.addEventListener('xsme:booking:complete', function(event) { console.log('رزرو در این ویجت تکمیل شد:', event.detail); }); </script>
